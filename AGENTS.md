# Project Rules

## Architecture
- Prefer composition over inheritance.
- Avoid unnecessary singletons.
- Keep classes focused on one responsibility.
- Reuse existing abstractions before creating new ones.

## C#
- Use [SerializeField] private for serialized fields.
- Use descriptive names.
- Private fields should be named from the "_" symbol
- Avoid unnecessary fields and checks.

## Unity
- Do not modify unrelated files or scenes.
- Do not delete assets without explicit approval.
- Preserve existing architecture.

## Git
- Never push changes automatically.
- Do not make destructive changes without approval.
